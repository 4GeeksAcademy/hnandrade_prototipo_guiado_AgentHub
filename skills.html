Qué es una skill

Una skill es una capacidad reutilizable y preconfigurada que se puede adjuntar a uno o más agentes de IA. En AgentHub amplía lo que cada agente puede ejecutar dentro de procesos financieros como conciliación, cumplimiento, riesgo, reportes o nómina.
